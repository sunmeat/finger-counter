# Finger Counter

React + Vite + MediaPipe Hand Landmarker. Считает, сколько пальцев (1–5) показано в веб-камеру.

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173 — разрешите доступ к камере.

## Как устроено

- `src/App.jsx` — камера, цикл распознавания, отрисовка скелета руки.
- `src/countFingers.js` — вся логика подсчёта по 21 точке руки (не зависит от поворота и от левой/правой руки).

Модель и wasm подгружаются из CDN при запуске, поэтому нужен интернет.
